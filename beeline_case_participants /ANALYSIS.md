# Анализ кандидатов для тарифных пилотов

## Что сделано

`candidate_engine.py` объединяет историю смен тарифов с текущей аудиторией и
ранжирует гипотезы вида:

`текущий тариф + ARPU-сегмент -> целевой тариф`.

Рейтинг учитывает:

- средний и медианный относительный рост ARPU после исторического перехода;
- долю положительных исторических переходов;
- количество наблюдений и штраф за маленькую выборку;
- частоту перехода среди переходов из той же исходной группы;
- размер и суммарный `predicted_arpu` доступной аудитории.

Кандидаты с отрицательной консервативной оценкой, долей успеха ниже 50%, пустой
аудиторией или недостаточным числом наблюдений отбрасываются.

## Первые гипотезы на выданных данных

При параметрах по умолчанию первые пять гипотез:

1. `tariff_4`, MID -> `tariff_8`: 408 наблюдений, аудитория 1 227.
2. `tariff_13`, MID -> `tariff_8`: 234 наблюдения, аудитория 1 022.
3. `tariff_8`, MID -> `tariff_10`: 182 наблюдения, аудитория 1 720.
4. `tariff_8`, LOW -> `tariff_9`: 26 наблюдений, аудитория 457.
5. `tariff_12`, MID -> `tariff_8`: 78 наблюдений, аудитория 342.

Это приоритеты для разведки, а не готовые финальные кампании. История описывает
другую аудиторию, поэтому реальную полезность каждой гипотезы должен подтвердить
`env.run_pilot()`.

## Контракт для разработчика агента

```python
from candidate_engine import build_candidates

candidates = build_candidates(
    change_history,
    env.customer_profile,
    env.tariffs,
    max_candidates=50,
)
```

Для запуска напрямую из папки starter kit:

```bash
python candidate_engine.py
```

Основные поля результата:

- `current_tariff`, `target_tariff`, `arpu_segment` — параметры пилота;
- `audience_size` — доступный размер сегмента;
- `history_count` — число исторических наблюдений;
- `positive_rate` — доля переходов с ростом ARPU;
- `conservative_lift` — исторический эффект со штрафом за ненадёжность;
- `candidate_score` — итоговый приоритет для сортировки.

Модуль не выбирает канал и не запускает пилоты: это ответственность
`agent.py`.

## Проверка

```bash
python -m unittest -v test_candidate_engine.py
```

Тесты проверяют выбор поддержанного прибыльного перехода и понятную ошибку при
неверной структуре входных данных.
