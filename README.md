# Beeline Tariff Campaign Agent

Локальное решение задачи по выбору маркетинговых кампаний для перехода
абонентов между тарифами.

## Подход

Решение состоит из двух частей:

1. `candidate_engine.py` анализирует историю смен тарифов и формирует
   ранжированные гипотезы с учётом роста ARPU, размера аудитории и надёжности
   исторической выборки.
2. `agent.py` проверяет лучшие гипотезы через `env.run_pilot()`, обновляет оценки
   по результатам пилотов и выбирает до 10 непересекающихся финальных кампаний.

Агент использует бесплатный `push` для разведки, после чего сравнивает
ожидаемую чистую выгоду доступных каналов с учётом бюджета и лимита контактов.

## Запуск

У папки starter kit есть пробел в конце имени, поэтому путь указан в кавычках:

```bash
cd "beeline_case_participants "
```

Проверка аналитического модуля:

```bash
python -m unittest -v test_candidate_engine.py
python candidate_engine.py
```

Проверка агента:

```bash
python local_eval.py
python local_eval.py --runs 10
```

Создание файла для сдачи:

```bash
python make_submission.py
```

## Локальная проверка

На десяти seed агент получил положительный результат в 10 случаях из 10:

- медианный чистый результат: `4 047 770`;
- минимальный: `2 762 871`;
- максимальный: `4 915 623`.

Эти числа получены на мок-модели. Они подтверждают корректность механики и
устойчивость стратегии, но не предсказывают балл на скрытой модели судейства.

Подробности аналитики находятся в
`beeline_case_participants /ANALYSIS.md`.
